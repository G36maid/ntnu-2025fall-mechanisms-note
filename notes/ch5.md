# 第五章：機構運動分析 ── 解析法

## 5.1 連桿組位置分析的解析法

### 5.1.1 幾何關係求解法

- **A 點座標**：
  - X_A = r₂ cos θ₂
  - Y_A = r₂ sin θ₂
- **B 點座標**：可透過 A 點或 O₄ 點求得。
  - (X_B - X_A)² + (Y_B - Y_A)² = r₃²
  - (X_B - X_O₄)² + (Y_B - Y_O₄)² = r₄²
- 聯立求解可得到 X_B 及 Y_B。
- 若求解結果為實數根，代表此連桿組有解；若為虛數根，則代表在目前的輸入角度下無解。
- 得到接點位置 B 或 B' 後，對應角度 θ₃ 與 θ₄ 可以透過 `tan⁻¹` 函數求得。

### 5.1.2 連桿組的向量迴路法

- 定義 R₁、R₂、R₃、R₄ 等變數後，可以得到此連桿組的位置向量方程式：
  - R₂ + R₃ - R₄ - R₁ = 0 (四連桿組)
  - R₂ + R₃ - R₁ = 0 (曲柄滑塊組)
- **複數向量表示**：
  - `R e^(jθ)`，其中 `e^(jθ) = cosθ + j sinθ` (尤拉等式)。
  - 向量每乘上一次運算元 j，結果的向量就會依逆時針方向旋轉 90 度。

### 5.1.3 銷接頭四連桿組的向量迴路方程式

- 位置向量方程式：`r₂e^(jθ₂) + r₃e^(jθ₃) - r₄e^(jθ₄) - r₁e^(jθ₁)` = 0
- 展開為實部和虛部：
  - **實部**：`r₂cosθ₂ + r₃cosθ₃ - r₄cosθ₄ - r₁cosθ₁ = 0`
  - **虛部**：`r₂sinθ₂ + r₃sinθ₃ - r₄sinθ₄ - r₁sinθ₁ = 0`
- 在已知桿長及固定樞軸位置 (r₁, r₂, r₃, r₄) 和 `θ₁ = 0` 的條件下，給定 θ₂ 可求得 θ₃ 和 θ₄。

### 5.1.4 曲柄滑塊四連桿組的向量迴路方程式

- 位置向量迴路方程式：`R₂ + R₃ - R₁` = 0
- 複數向量表示：`r₂e^(jθ₂) + r₃e^(jθ₃) - r₁e^(jθ₁)` = 0
- 展開為實部和虛部 (假設 θ₁ = 0 且 r₁ 為滑塊位移)：
  - **實部**：`r₂cosθ₂ + r₃cosθ₃ - r₁ = 0`
  - **虛部**：`r₂sinθ₂ + r₃sinθ₃ = 0`
- 在已知 r₂、r₃ 和 `θ₁ = 0` 的條件下，給定 θ₂ 可求得 θ₃ 和 r₁。

### 5.1.5 倒置曲柄滑塊四連桿組位置向量方程式

- 位置向量迴路方程式：`R₂ - R₃ - R₄ - R₁` = 0
- 複數向量表示：`r₂e^(jθ₂) - r₃e^(jθ₃) - r₄e^(jθ₄) - r₁e^(jθ₁)` = 0
- 假設 `θ₁ = 0`，且 `θ₄ = θ₃ + φ` (φ 為固定角度)。
- 展開為實部和虛部：
  - **實部**：`r₂cosθ₂ - r₃cosθ₃ - r₄cos(θ₃ + φ) - r₁ = 0`
  - **虛部**：`r₂sinθ₂ - r₃sinθ₃ - r₄sin(θ₃ + φ) = 0`
- 給定 θ₂ 可求解 θ₃，再代回可求 r₁。

### 5.1.6 連桿上任意點之速度

- 求得各連桿之角度後，連桿上任意點之位置可由其相對位置關係微分得到。

## 5.2 多於四根連桿的連桿組的分析

- 一個向量方程式只能解兩個未知數。
- 多於四根連桿的連桿組需要尋找額外之方程式來求解。

### 5.2.1 瓦特六連桿組及其位置向量迴路

- 可能的封閉向量迴路：
  - `R₂ + R₃ - R₄ - R₁ = 0`
  - `R₅ + R₆ - R₇ - R₈ = 0`
- 通常已知 `r₁` 到 `r₈`，但有六個未知角度。
- 需要利用同一桿件上兩個向量的角度固定關係來提供額外方程式，例如 `θ₄ = θ₅ + φ`。

### 5.2.2 史蒂文生六連桿組的分析

- 可能的封閉向量迴路：
  - `R₂ + R₃ - R₄ - R₁ = 0`
  - `R₄ + R₅ - R₆ - R₇ - R₈ = 0`
- 同樣需要利用同一桿件上兩個向量的角度固定關係，例如 `θ₃ = θ₅ + π`。

## 5.3 四連桿組的速度方程式

### 5.3.1 銷接頭四連桿組的速度方程式

- 位置向量方程式：`r₂e^(jθ₂) + r₃e^(jθ₃) - r₄e^(jθ₄) - r₁e^(jθ₁)` = 0
- 對時間微分可得速度方程式：
  - `j r₂ω₂e^(jθ₂) + j r₃ω₃e^(jθ₃) - j r₄ω₄e^(jθ₄)` = 0 (因為 r₁ 固定，θ₁ = 0，其微分為 0)
- 展開為實部與虛部：
  - **實部**：`-r₂ω₂sinθ₂ - r₃ω₃sinθ₃ + r₄ω₄sinθ₄ = 0`
  - **虛部**：`r₂ω₂cosθ₂ + r₃ω₃cosθ₃ - r₄ω₄cosθ₄ = 0`
- 聯立求解這兩個方程式可得到 ω₃ 和 ω₄。

### 5.3.2 曲柄滑塊四連桿組的向量迴路方程式與速度方程式

- 位置向量方程式：`r₂e^(jθ₂) + r₃e^(jθ₃) - r₁e^(jθ₁)` = 0
- 對時間微分可得速度方程式：
  - `j r₂ω₂e^(jθ₂) + j r₃ω₃e^(jθ₃) - ω₁e^(jθ₁)` = 0 (其中 `dr₁/dt` 代表滑塊速度)
- 展開為實部與虛部 (假設 `θ₁ = 0`):
  - **實部**：`-r₂ω₂sinθ₂ - r₃ω₃sinθ₃ + dr₁/dt = 0`
  - **虛部**：`r₂ω₂cosθ₂ + r₃ω₃cosθ₃ = 0`
- 由虛部可得 ω₃，代入實部可得滑塊速度 `dr₁/dt`。

### 5.3.3 連桿上任意點之速度

- 求得各連桿之角速度後，連桿上任意點之速度可由其位置向量微分得到。

## 5.4 加速度分析的解析法

### 5.4.1 銷接頭四連桿組

- 由速度方程式對時間微分可得加速度方程式：
  - `(-r₂ω₂² + j r₂α₂)e^(jθ₂) + (-r₃ω₃² + j r₃α₃)e^(jθ₃) - (-r₄ω₄² + j r₄α₄)e^(jθ₄)` = 0
- 展開為實部與虛部：
  - **實部**：`-r₂ω₂²cosθ₂ - r₂α₂sinθ₂ - r₃ω₃²cosθ₃ - r₃α₃sinθ₃ + r₄ω₄²cosθ₄ + r₄α₄sinθ₄ = 0`
  - **虛部**：`-r₂ω₂²sinθ₂ + r₂α₂cosθ₂ - r₃ω₃²sinθ₃ + r₃α₃cosθ₃ + r₄ω₄²sinθ₄ - r₄α₄cosθ₄ = 0`
- 聯立求解可得到 α₃ 和 α₄。

### 5.4.2 曲柄滑塊四連桿組加速度方程式

- 由速度方程式對時間微分可得加速度方程式：
  - `(-r₂ω₂² + j r₂α₂)e^(jθ₂) + (-r₃ω₃² + j r₃α₃)e^(jθ₃) - α₁e^(jθ₁)` = 0 (其中 `d²r₁/dt²` 代表滑塊加速度)
- 展開為實部與虛部 (假設 `θ₁ = 0`):
  - **實部**：`-r₂ω₂²cosθ₂ - r₂α₂sinθ₂ - r₃ω₃²cosθ₃ - r₃α₃sinθ₃ + d²r₁/dt² = 0`
  - **虛部**：`-r₂ω₂²sinθ₂ + r₂α₂cosθ₂ - r₃ω₃²sinθ₃ + r₃α₃cosθ₃ = 0`
- 由虛部可得 α₃，代入實部可得滑塊加速度 `d²r₁/dt²`。

### 5.4.3 倒置曲柄滑塊四連桿組加速度方程式

- 由位置向量迴路方程式對時間進行兩次微分，結合 `θ₄ = θ₃ + φ`，可得到加速度方程式。
- 最終分解為實部與虛部，聯立求解可得到 `r₁`、`ω₃`、`α₃` 等未知量。

## 5.5 本章重點整理

- **位置分析**：
  - **三角幾何法**：著重於桿長的幾何關係並應用三角函數求解。
  - **向量迴路法**：利用連桿組所形成之封閉向量迴路求解，需注意一個向量迴路方程式僅能解兩個未知數。
- **速度分析 (複數法)**：
  - 可求得任意輸入瞬間，輸出之函數解。
  - 可利用電腦程式算出整個周期中輸出運動之數值及變化關係。
- **加速度分析 (複數法)**：
  - 須注意時間變數為哪些項，如此在微分求解時才不會有遺漏。
