# 第一章：基本概念

## 1.1 機械、機構與機件

### 機構、機器的定義

**機構**：
- 多個機件聯接，使機件產生固定之運動但不一定可作功
- 例如：摺椅中之"摺疊機構"

**機器**：
- 兩個以上機件的組合體，可將能量轉變為有用的功
- 例如：腳踏車、縫紉機等都是機器

### 1.1.1 機械 (machine)

將一些固定及活動的剛性物體，配置在產生能量的動力源與輸出能量的作功物之間，做為彼此能量轉換的工具，使彼此能相互適應各得其所，此即所謂的「機械」或「機器」。

一部機械之組成，至少應包括以下三個部分：
1. 接受能量的部分
2. 將接受之能量加以轉換或傳遞的部分
3. 產生「功」或預期效果的部分

在機器中本身固定不動但支撐活動元件的部分稱為**機架 (frame)**

### 1.1.2 機構 (mechanism)

**重要概念定義**：
- **連桿 (link)**：在一部機器中，對其它物體有相對運動者稱之
- **運動鏈 (kinematic chain)**：指一組連桿系統，也就是一群連在一起或相互接觸，而可以做相對運動的剛體
- **剛體 (rigid body)**：係指不因外力而發生變形之物體（在機動學中，並不考慮機器上任何結構的變形）

**拘束運動鏈**：
若運動鏈其中的一根連桿固定，而其它任一根連桿移動至新位置時，將導致其餘連桿移動至可預知的位置，則此系統稱之為「拘束運動鏈 (constrained kinematic chain)」，或稱機構 (mechanism)。

**無拘束運動鏈**：
如果其中一根連桿固定，但根據其它任一根連桿移動並無法預知其餘連桿的位置，則稱此系統為無拘束運動鏈 (unconstrained kinematic chain)。

**結構 (structure) 或架構 (truss)**：
三根連桿互相釘在一起，此種裝置不能構成一組運動鏈，因為其元件之間，沒有相對運動，所以不是機構。

### 機構與機械之異同

**相同之處**：
- 兩者各機件之間，必須要有相對之運動

**不同之處**：
- **機構**：只是用來傳遞或變換運動之機件組合
- **機械**：用來傳遞或變換能量之機件組合，必須作功

> 注意：所謂機械能做功，並不是指機械本身能產生能量而作功，必須有外界之能源加諸於機械，方能使其作功。

## 1.2 機動學

### 機械運動學 (kinematics of machines)
探討機械元件之間相對運動的學問（位移、速度及加速度），並不考慮各機件受力之大小，也不管各機件本身質量之多寡。

### 機械動力學 (dynamics of machines)
研究作用在機械元件上的力與經由此力所造成的運動（力、質量、物體的尺寸大小與力施於物體上後產生的運動變化），通常在確定運轉中的元件是否達到平衡，或是強度是否安全時，都必須作動力分析。

### 近代機動學分類

**機動分析學 (mechanism analysis)**：
- 分析已有機構之運動性質及法則

**機動合成學 (mechanism synthesis)**：
- 研究如何藉指定之運動條件，合成所需之機構

### 機構學分類

機構學可分為機構的**分析(Analysis)**與**合成(Synthesis)**兩大類：

**機構分析**包括：
- 機構的構造分析(Structural analysis)
- 運動分析(Kinematic analysis)
- 分析已有機構的可動性與運動狀態

**機構合成**包括：
- 機構的構造合成(Structural synthesis)
- 運動合成(Kinematic synthesis)
- 依照機構之可動性與運動上的要求，設計出合乎所求的機構構造與幾何尺寸

## 1.3 機件之對偶與運動鏈

### 1.3.1 運動圖 (kinematic diagram)
為了便於研究機件間各種運動，慣以簡單的線條勾繪機件，但只著重於影響運動的尺寸長度及位置，其它均不考慮。此即所謂的運動圖。

### 1.3.2 機件之對偶 (pairing)
一部機器係由許多的機件所組成的，任兩物體相接觸則構成一對偶。

**低對 (lower pairing)**：
- 兩物體若是面與面接觸就構成低對
- 低對包含旋轉或銷接頭
- 例如：軸承、活塞與汽缸壁

**高對 (higher pairing)**：
- 不考慮機件變形，若兩物體係以點或線的接觸為高對
- 例如：滾動軸承、齒輪、凸輪
- 高對會造成較大的磨損

### 1.3.3 接頭 (joint)
在一部機械中，將連桿聯結在一起的部分。

**特性**：
- 接頭允許連桿之間彼此作相對運動
- **旋轉接頭 (revolute joint)**：只允許另外一根連桿作平面運動
- **球接頭 (sphere joint)**：具有三個自由度，允許有三個角度的相對運動

### 1.3.4 自由度 (degree of freedom)

**定義**：
相對於機架或固定桿而言，確定每一根連桿位置所需的最少獨立參數 (independent parameter) 之數目。

**基本概念**：
- 對一不受任何拘束之剛體而言，其具有**六個自由度**（三個座標方向平移和三個座標方向旋轉）
- 一個只在平面運動之剛體則具有**三個自由度**（兩個座標方向平移和在該平面上之旋轉）

**古柏方程式 (Gruebler's equation)**：
對平面運動鏈的自由度可利用古柏方程式計算：

**F = 3(L-1) - 2P₁ - P₂**

其中：
- F：平面運動鏈的自由度
- L：連桿數總和
- P₁：具有一個自由度之對偶數
- P₂：具有二個自由度之對偶數目

**判斷準則**：
- F = 1：拘束運動鏈（機構）
- F > 1：無拘束運動鏈
- F ≤ 0：呆鏈，也就是架構或結構

### 例題

**例題1.1**：
L = 4, P₁ = 5, P₂ = 0
F = 3(4-1) - 2×5 - 0 = 9 - 10 = -1
結果：結構

**例題1.2**：
L = 6, P₁ = 7, P₂ = 0
F = 3(6-1) - 2×7 - 0 = 15 - 14 = 1
結果：機構

**例題1.3**：
L = 4, P₁ = 3, P₂ = 2
F = 3(4-1) - 2×3 - 2 = 9 - 6 - 2 = 1
結果：機構

**例題1.5（挖土機）**：
L = 12, P₁ = 12, P₂ = 3
F = 3(12-1) - 2×12 - 3 = 33 - 24 - 3 = 6
結果：無拘束運動鏈

### 1.3.5 常用之簡圖符號

在機動學中常只用簡單之圖形，說明機件之連配情形與相關位置，使分析更明瞭。

**基本符號**：
- ●：機件之一質點或一點
- ○：旋轉對，相當於用銷所形成之樞軸 (pivot)
- ⊗：代表位置固定之旋轉對
- ——：連桿，若連桿為彎曲者，可畫為曲線
- ///：固定件或分析運動時當作靜止之機件

## 1.4 應用實例

### 汽車主要構造
汽車是機械系統的典型例子，包含了各種機構來實現不同的功能。

### 拳擊賽的遊樂機械
這是無拘束運動鏈的一個實際應用例子，展示了機構在娛樂設備中的應用。

### 搖動自行車
自行車的機構設計展示了如何將人力轉換為推進力，是機械原理的經典應用。

## 重點整理

1. **機構 vs 機器**：機構傳遞運動，機器傳遞能量並作功
2. **自由度計算**：使用古柏方程式 F = 3(L-1) - 2P₁ - P₂
3. **對偶分類**：低對（面接觸）vs 高對（點/線接觸）
4. **運動鏈類型**：
   - F = 1：拘束運動鏈（機構）
   - F > 1：無拘束運動鏈
   - F ≤ 0：結構
5. **機動學分支**：分析學與合成學
