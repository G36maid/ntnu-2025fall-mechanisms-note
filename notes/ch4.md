# 第四章：連桿機構運動分析 ── 圖解法

## 4.1 概論

### 運動分析的重要性
- 在設計完成一個機構後，有必要確認在運轉時是否有不可預期之狀況出現而產生失效甚至破壞，因此需要針對該機構加以分析。

### 位置分析
- **目的**：了解所設計機構之佔地面積、特殊位置（如肘節位置）及桿件間力量傳動的夾角大小。
- **作用**：判斷所設計的機構是否能順利運轉。

### 速度與加速度分析
- **目的**：
  - 根據牛頓第二運動定律，作用力與加速度成正比，藉此了解機構運轉時作用力的大小。
  - 計算加速度需要先找出對應於各輸入運動增量時，機構所有元件的位置。
- **後續應用**：作為後續元件尺寸設計、強度分析及驅動元件選用之依據。

## 4.2 座標系統

### 座標系統類型
1.  **整體座標系統 (Global coordinate system, GCS)**：
    - 標記為 X, Y。
    - 不會隨時間變動的主要座標系統。
    - 常用的整體座標系統是沒有加速度的，稱為**慣性參考座標系統 (inertial reference frame)**。

2.  **局部座標系統 (Local coordinate system, LCS)**：
    - 標記為 x, y。
    - 相對於整體座標系統進行時變的座標系統。

### 向量表示法
- 機構中各連桿的位置、速度與加速度的關係通常以向量表示。
- **極座標形式**：R∠θ
- **直角座標形式**：xi + yj
- **複數座標形式**：R(cosθ + j sinθ) 或 Re^(jθ)

## 4.3 位置與位移

### 位置向量
- 平面上的位置可以用位置向量表示。
- **直角座標與極座標轉換**：
  - R = √(X² + Y²)
  - θ = tan⁻¹(Y/X)

### 位移
- **定義**：一個點的位移是其位置的改變量，可用該點相對於座標系統的起始位置和終止位置之間的直線距離表示。
- **向量表示**：
  - 向量 R_B/A = R_B - R_A 代表 B 點與 A 點間的位置差異或位移。
  - 絕對位置是指相對於整體座標系統的原點 (O)。
  - R_B/A = R_B/O - R_A/O
- **相對位置 (relative position)**：相異的質點 A 與質點 B 在同一個座標系統內移動時的位置關係。

## 4.4 連桿組位置分析的圖解法

- **適用對象**：銷接頭四連桿組。
- **已知條件**：桿件長度及固定樞軸位置 (r₁, r₂, r₃, r₄) 為已知，輸入桿件 (一般設定為第二桿) 與接地桿件的角度 (θ₂) 也為已知。
- **向量方程式**：R₁ + R₂ + R₃ + R₄ = 0 (向量和為零)
- **解答可能性**：
  - **開放組合**：聯結桿件與接地桿件並未相交。
  - **封閉組合**：聯結桿件與接地桿件相交 (由虛線組成)。

## 4.5 傳動角

- **定義**：輸出桿與聯結桿之間的夾角 (μ 角)。
- **計算**：取這兩根連桿的銳角夾角之絕對值。
- **影響**：影響接頭之傳遞力量與傳動速度的品質。
- **最佳值**：90°。
- **設計考量**：當傳動角小於 45° 時，徑向分量會大於切線分量。大多數的機器設計會把最小傳動角維持在 40° 以上，以確保順暢運轉與良好的力量傳遞。

## 4.6 極限條件

- **肘節位置 (Toggle Position)** 或稱**停駐位置 (Stationary Configuration)**：
  - 發生在兩根移動連桿的共線處。
  - 可透過位置分析得知。

## 4.7 速度分析之相對速度法

### 方法比較
- **解析法 (analytical method)**：計算較複雜，適合求解多個相位。
- **圖解法 (graphical method)**：較容易求解，精確度高，適用於求解單一相位。
- **相對速度法**：具有與相對加速度法的一貫性，更重要且有效。

### 相對速度法步驟
- **已知條件**：曲柄的角速度 ω₂ (例如反時針方向旋轉)，欲求滑塊速度 V_C。
- **向量方程式**：V_C = V_B + V_C/B (或 V_C = V_O + V_B/O + V_C/B)
  - V_B 的方向垂直 OB 桿，大小為 V_B = OB · ω₂。
  - V_C 的方向沿滑塊運動方向。
  - V_C/B 的方向垂直 BC 桿。
- **圖解法**：繪製速度多邊形，通過量測線長來求解未知速度的大小和方向。

### 注意事項
- **V_C/B**：表示 C 點對 B 點之相對速度，如視 B 為固定，則 C 點繞 B 點旋轉。
- **V_B/C**：表示 B 點相對 C 點的速度，在速度圖上，為通過 B\' 及 C\' 點且自 C\' 畫至 B\'，且垂直 BC 桿。
- **O\'**：表示相對於絕對速度為零的點，速度圖必通過 O\' 及 B\'。

## 4.8 複式連桿組的速度

- **浮動桿 (floating link)**：機構中任一連桿若無固定的旋轉中心。
- **複雜機構 (complex mechanism) 或複式連桿組**：機構中具有兩個或兩個以上的浮動桿。
- **求解方法**：
  - 若已知條件為曲柄的角速度，可直接用相對速度法求解。
  - 若已知條件為滑塊的線速度，速度方程式中可能會有太多未知數，需採用**試誤法 (trial-and-error)**。

## 4.9 法線與切線加速度法

### 加速度分量
- 質點作曲線運動時，速度方向的改變量可分成兩個分量：
  1.  **法線加速度 (normal acceleration, A_n)**：
      - 與運動路徑垂直。
      - 由切線速度方向的改變產生。
      - A_n = V²/R = Rω² (其中 R 為曲率半徑或旋轉半徑)。
      - 若質點作直線運動則無法線加速度 (A_n = 0)。
  2.  **切線加速度 (tangential acceleration, A_t)**：
      - 與運動路徑相切。
      - 由切線速度大小的改變產生。
      - A_t = dV/dt = Rα (其中 α 為角加速度)。

- **總加速度 (A)**：
  - A = A_t + A_n (向量和)
  - 大小：|A| = √(A_t² + A_n²)
  - 與曲率半徑 (或旋轉半徑) 之夾角：φ = tan⁻¹(A_n/A_t)

## 4.10 加速度圖

### 加速度像與角加速度
- **相對加速度關係**：A_P/Q = A_P - A_Q
- 同一連桿上任兩點相對加速度的大小與兩點間的距離成正比。

### 浮動桿的加速度
- 求解過程通常需要分解為法線和切線分量。

### 滾動元件之加速度
- **外接式的滾動接觸**：
  - A_C = A_P + A_C/P
  - A_C/P = (A_C/P)_t + (A_C/P)_n
  - 法線加速度計算：A_nC = V_C² / (R₁ + R₂)
- **內接式的滾動接觸**：
  - A_nC = V_C² / (R₁ - R₂) (注意減號)
- 若物體1是平面，則 R₁ 為無限大，A_nC = 0。
- 若外形非圓形，則 R₁ 和 R₂ 為接觸點處的曲率半徑。

## 4.11 柯氏加速度 (Coriolis Acceleration)

- **定義**：當物體3上的點沿著物體2上的路徑運動，且物體2又在旋轉時，物體3上與物體2上接觸點的相對加速度具有柯氏分量 (A_coriolis)。
- **大小**：A_c = 2 * V_P/F * ω_F (其中 V_P/F 為點 P 相對於參考框架 F 的相對速度，ω_F 為參考框架 F 的角速度)。
- **方向**：由滑塊速度方向，以參考物體（物體2）的角速度之轉向方向旋轉 90 度，便可求得柯氏加速度的方向。

## 4.12 本章重點整理

1.  **圖解法在位置分析中的應用**：
    - 快速獲得特定位置的近似解。
    - 精確性受作圖能力限制。

2.  **速度分析之相對速度法**：
    - 基於相對運動及剛體原理。
    - 可求解機構中點的絕對速度及相對速度。
    - 作為加速度分析之依據。

3.  **加速度分析**：
    - 相對困難。
    - **切線與法線加速度**：
      - 非直線運動必有法線加速度與切線加速度。
      - 直線運動無法線加速度。
      - 圓周運動時，除非角速度改變，否則無切線加速度。
    - **加速度多邊形的繪製**：本章重點，加速度方向務必正確。
    - **滾動元件的加速度**：除法線加速度稍有改變外，其餘與直線運動相同。
