# 第二章：機械之運動

## 2.1 機械運動之種類

### 2.1.1 平面運動

**定義**：
凡一運動體內之各質點均在平行某參考平面的平面上運動，則稱此物體的運動為平面運動。

- 此參考平面稱之為**運動面 (plane of motion)**
- 平面運動可分為平移、旋轉及平移與旋轉的組合三大類型

#### 一、平移 (translation)

**定義**：
凡是運動物體內的所有直線，移動前、後均互相平行，則稱該物體的運動為平移運動。

**分類**：
1. **直線平移 (rectilinear translation)**：
   - 物體內各質點以直線路徑移動
   - 例如：滑塊的運動

2. **曲線平移 (curvilinear translation)**：
   - 物體內所有質點係沿著曲線路徑運動
   - 例如：平行曲柄機構中的連桿運動

#### 二、旋轉 (rotation)

**定義**：
若運動物體內各質點均與其垂直於運動面之直線保持固定距離運動，則此運動稱之為旋轉。

**特性**：
- 此直線稱之為**旋轉軸 (axis of rotation)**
- 各質點則繞此軸作圓周軌跡運動
- 例如：連桿繞機架作旋轉運動

#### 三、平移和旋轉

機件的許多運動都是平移和旋轉互相組合而成的，而此組合運動均可分成平移與旋轉，但卻與發生的先後順序無關。

### 2.1.2 螺旋運動 (helical motion)

**定義**：
若一點以等距離繞一軸旋轉，同時又平行該軸移動，則此點的軌跡稱之為**螺旋線 (helix)**。若物體內各質點之運動軌跡均是螺旋線，則稱該物體作螺旋運動。

### 2.1.3 球面運動 (spherical motion)

**定義**：
若一點在三度空間中，以等距離繞某一點運動稱之為球面運動，亦即運動體中各質點繞同一個定點運動，各質點之路徑均在同心圓球面上。

### 2.1.4 週期運動

**循環 (cycle)**：
若一機構的運動，自起始點開始，經過所有可能的路徑組合後，再回到起始點，則稱此機構完成一循環運動。

**重要概念**：
- **週期 (period)**：完成一循環所需的時間
- **頻率 (frequency)**：週期的倒數，表示單位時間內所完成的循環數
- **相位 (Phase)**：在機構的循環運動中，連桿在任一瞬間的相對位置

## 2.2 主動件與從動件

**主動件 (driver) 或原動件**：
在一組機構之中，由動力運轉輸入而運動的構件

**從動件 (follower)**：
其它構件，由於原動件的運動傳遞而運動者

### 2.2.1 倒置 (inversion)

將運動鏈中不同的連桿固定，就可以得到不同的機構。滑塊曲柄機構可衍生出四種不同機構：

1. **汽油及柴油引擎使用的機構**
2. **早期的星形飛機引擎使用的機構** 
3. **玩具的擺動及汽缸蒸汽引擎使用的機構**
4. **泵使用的機構**

## 2.3 機械運動的傳遞方式

### 一、直接接觸 (direct contact)

**定義**：
藉由主動件與從動件之直接接觸，以獲得機械傳動之目的。

**例子**：
- 凸輪
- 齒輪
- 摩擦輪

### 二、間接接觸

**定義**：
主動件與從動件間，另有其它中間媒體傳遞機構。

**類型**：

1. **剛性聯接桿**：
   - 例如：連桿
   - 運動係由主動件透過連桿傳到從動件

2. **撓性聯結桿**：
   - 例如：皮帶、鏈條
   - 具有彈性的聯結方式

3. **液壓流體聯結**：
   - 利用液壓流體做為中間聯結管道
   - 優點：噪音小、機構簡單、振動小
   - 例如：液壓機

4. **磁場聯結**：
   - 在電動馬達中，由電能的作用產生轉動
   - 磁場扮演聯結體的角色

## 2.4 向量與比例尺

在研究機動學時所討論的物理量可分為兩類：

### 純量 (scalar)
僅含有大小之物理量，如：
- 距離
- 面積
- 時間
- 質量

### 向量 (vector)
具有大小、方向的量，如：
- 力
- 位移
- 速度
- 加速度

**向量表示法**：
- 向量可以用帶有箭頭的線段來表示
- 箭頭代表向量的頭(head)或終點(terminus)
- 另一端稱為尾(tail)或起始點(origin)
- 向量的方向用與水平軸(X軸)在逆時針方向所夾的角度為正量來表示

### 2.4.1 向量的加法與減法

**向量加法**：
- 可以用圖解法來表示
- 向量加法具有交換性，即 A+B 與 B+A 相同

**向量減法**：
- 向量的減法可由向量的合成得到
- 如欲求 A-B，可寫成 A+(-B)
- 向量減法不具交換法則

### 2.4.2 向量的合成與分解

**合成 (composition)**：
- 將兩個或兩個以上向量相加，稱為合成
- 總和稱**合成向量 (resultant)**
- 構成此合成向量的每一向量，稱為合成向量的**分量 (component)**

**分解 (resolution)**：
- 將任一已知的向量分解成任意數目的分量
- 任何向量均可分解成無限多組的分量
- 若一個向量被分解成二個分量，當四個量中的任何兩個量為已知時，其餘的兩個量也可以求出

## 2.5 絕對運動與相對運動

### 絕對運動 (absolute motion)
指一個物體相對於某一靜止物體的運動。

**特點**：
- 由於在宇宙之中並無絕對靜止的物體，故任何物體的運動必須用相對於其它物體的運動來表示
- 在大部分運動學的例子中都視地球為靜止不動，所以物體對於地球的運動，可視之為絕對運動

### 相對運動
若兩物體彼此的絕對速度有差異時，稱它們彼此之間有相對運動。

**運動關係式**：
- 物體A相對於物體B的位移 = 物體A的絕對位移 - 物體B的絕對位移
- 相對速度與相對加速度的作法亦同

**速度關係**：
- V_A/B = V_A - V_B
- V_B/A = V_B - V_A
- V_B = V_A + V_B/A

**角運動關係**：
- θ_M/N = θ_M - θ_N
- ω_M/N = ω_M - ω_N  
- α_M/N = α_M - α_N

其中逆時針方向為正，順時針方向時為負。

## 2.6 線位移與速度

### 基本概念

**路徑 (path)**：質點運動連續位移的軌跡

**距離 (distance)**：運動路徑的長度，為純量

**位移 (displacement)**：質點所在位置的改變量，為向量

### 位移計算

質點P沿著曲線路徑運動，其線位移為位置向量的差：

**s = Δx + Δy** ... (2.7)

位移的大小：
**|s| = √(Δx² + Δy²)** ... (2.8)

相對於x軸的方向：
**θ = tan⁻¹(Δy/Δx)** ... (2.9)

### 線速度

**平均速度**：
**V_av = s/t = lim(Δt→0) Δs/Δt** ... (2.10)

**瞬時速度**：
**V = ds/dt** ... (2.11)

假設位移無限小時，向量s會逐漸接近路徑上的點，所以在任何瞬間，質點的運動方向與其路徑相切。

### 例題

**例題2.1**：
一物體作直線運動，已知其位移與時間的關係式為 S = 2t³ - 4t² + 5t (cm)，試求在 t = 3 sec 時之速度為何？

解：
V = dS/dt = d(2t³ - 4t² + 5t)/dt = 6t² - 8t + 5
當 t = 3 sec 時：
V = 6(3)² - 8(3) + 5 = 54 - 24 + 5 = 35 cm/sec

**例題2.2**：
有一汽車在 10 秒共移動了 500 公尺距離，試求其平均速度。

解：
V_av = s/t = 500/10 = 50 m/sec

## 2.7 角位移與角速度

### 角速度定義

若有一物體對固定軸O旋轉，當點P移動到P'時，線段OP在時間t內移動了角度θ：

**平均角速度**：
**ω_av = θ/t** ... (2.11)

**瞬時角速度**：
**ω = lim(Δt→0) Δθ/Δt = dθ/dt**

### 線速度與角速度關係

點P的速度V與路徑相切且與OP垂直，弧長等於Rθ：

**V = lim(Δt→0) RΔθ/Δt = R(dθ/dt) = Rω** ... (2.12)

其中ω以單位時間的弧度量(rad)來表示。

### 轉速換算

角速度常以每分鐘轉數n來表示：

**ω = 2πn/60** ... (2.13)
**V = 2πRn/60** ... (2.14)

### 不同半徑質點的速度關係

旋轉體上的所有質點都有相同的角速度，各質點線速度的大小與其旋轉半徑成正比：

**V_A/V_B = R_A/R_B** ... (2.15)

### 例題

**例題2.3**：
有一直徑為200mm之鋼棒，在車床上加工，其切削速度為45 m/sec，則其旋轉速度為多少 rpm？若繼續切削至直徑為100mm時，則切削速度為多少？

解：
(1) v = 45 m/sec，R = 200/2/1000 = 0.1 m
    ω = v/R = 45/0.1 = 450 rad/sec
    n = 60ω/2π = 60×450/2π ≈ 4297 rpm

(2) R = 100/2/1000 = 0.05 m
    v = Rω = 0.05×450 = 22.5 m/sec

## 2.8 線加速度與角加速度

### 線加速度

**定義**：指線速度對時間的變化率

**平均加速度**：
**A_av = (V - V₀)/t** ... (2.16)

**瞬時加速度**：
**A = lim(Δt→0) ΔV/Δt = dV/dt** ... (2.17)

或：
**A = d²s/dt²** 

### 等加速度運動公式

若質點以等加速度運動，則加速度A為常數：

1. **V = V₀ + At** ... (2.18)
2. **S = (V + V₀)t/2** ... (2.19)  
3. **S = V₀t + (1/2)At²** ... (2.20)
4. **V² = V₀² + 2As** ... (2.21)

### 角加速度

**定義**：指角速度對時間的變化率

**α = dω/dt = d²θ/dt²** ... (2.22)

### 等角加速度運動公式

若物體作等角加速度運動，則α為常數：

1. **ω = ω₀ + αt** ... (2.23)
2. **θ = (ω + ω₀)t/2** ... (2.24)
3. **θ = ω₀t + (1/2)αt²** ... (2.25)
4. **ω² = ω₀² + 2αθ** ... (2.26)

### 例題

**例題2.4**：
a) 若一汽車在 89.3 公尺內，以等加速度由32.2 km/h 的速度加速到96.6km/h。求其加速度大小為多少？
b) 若一汽車在 5 秒時間內，以變加速度由32.2 km/h 的速度加速到96.6km/h。求其平均加速度大小為多少？

解：
(a) v₀ = 32.2×1000/3600 = 8.94 m/s
    v = 96.6×1000/3600 = 26.83 m/s
    s = 89.3 m
    
    使用 v² = v₀² + 2as
    a = (v² - v₀²)/(2s) = (26.83² - 8.94²)/(2×89.3) = 3.58 m/s²

(b) A_av = (v - v₀)/t = (26.83 - 8.94)/5 = 3.58 m/s²

**例題2.5**：
有一飛輪由靜止起動，在 5 秒內有一等角加速度 4 rad/sec²，求其：
(a) 末角速度
(b) 5 秒內的平均角速度  
(c) 5 秒內所轉動的角度

解：
(a) ω = ω₀ + αt = 0 + 4×5 = 20 rad/sec
(b) ω_av = (ω₀ + ω)/2 = (0 + 20)/2 = 10 rad/sec
(c) θ = ω₀t + (1/2)αt² = 0×5 + (1/2)×4×5² = 50 rad

## 2.9 簡諧運動 (simple harmonic motion)

### 定義

簡諧運動是一種直線運動，它的運動型式顯示出距某一定點的位移和加速度成正比，而方向又彼此相反。

**數學式**：
**A = -Kx** ... (2.27)

其中：
- A = 加速度
- x = 位移  
- K = 常數

### 簡諧運動的表示

以一質點P作等角速度圓周運動在圓直徑上的投影來代表簡諧運動：

**位移**：**x = R cos ωt** ... (2.28)
**速度**：**V = dx/dt = -Rω sin ωt** ... (2.29)
**加速度**：**A = d²x/dt² = -Rω² cos ωt = -ω²x** ... (2.30)

### 蘇格蘭軛機構

蘇格蘭軛 (Scotch-Yoke) 機構中，滑塊以等角速度旋轉，則從動件連桿將作簡諧運動。

### 例題

**例題2.6**：
當一質點在水平作簡諧運動時，以週期5秒移動60cm，試求在離開右端6cm時之加速度及速度。

解：
R = 60/2 = 30 cm
T = 5 秒，故 ω = 2π/T = 2π/5 rad/sec
x = 6 cm

速度：V = ω√(R² - x²) = (2π/5)√(30² - 6²) = (2π/5)√864 ≈ 37 cm/sec
加速度：A = -ω²x = -(2π/5)² × 6 ≈ -9.5 cm/sec²

## 2.10 應用實例

### 樹猴機械
樹猴(tree monkey)的機械，它可以攀登樹幹而自動修剪樹枝，動作是依螺旋狀繞著樹幹上升或下降。其構造重點是使用與垂線成一斜度的輪子，並保持其中三個輪子與樹幹接觸，如此可以做到類似於人類的爬樹動作。

### 自動唱機送片機構  
自動唱機送片機構的功能是將唱片由唱片架取出，並放置於轉盤上以供唱針播放，需要與人手臂動作類似的迴轉機構。當它由架上選取唱片後，便向轉盤處靠近，同時依唱片的正面或反面扭轉180°或90°，再放置到唱盤上，收回時依反向動作操作。

## 重點整理

### 運動分類
1. **平面運動**：平移、旋轉、平移+旋轉組合
2. **螺旋運動**：繞軸旋轉同時平行軸移動
3. **球面運動**：繞定點等距離運動
4. **週期運動**：具有循環性的運動

### 傳動方式
1. **直接接觸**：齒輪、凸輪、摩擦輪
2. **間接接觸**：連桿、皮帶、液壓、磁場

### 重要公式
1. **線運動**：v = ds/dt，a = dv/dt
2. **角運動**：ω = dθ/dt，α = dω/dt  
3. **速度關係**：v = rω
4. **簡諧運動**：x = R cos ωt，a = -ω²x

### 關鍵概念
- 絕對運動 vs 相對運動
- 向量的合成與分解
- 等加速度運動公式
- 簡諧運動特性
