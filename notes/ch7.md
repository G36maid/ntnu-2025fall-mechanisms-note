# 第七章：凸輪機構

## 7.1 凸輪的型式

### 定義與特性
- **凸輪 (cam)**：使從動件按其指定運動作動的簡單機構。
- **運動特性**：凸輪表面或槽溝形狀複雜，但其運動是簡單的旋轉、搖擺或滑行。
- **從動件特性**：形狀簡單，運動以直線往復或搖擺者居多。
- **優點**：可將簡單的運動輸入轉換成預定的複雜運動，尤其適合從動件在運動循環中需要某階段停留時。
- **缺點**：
    - 凸輪與從動件的接觸以點和線的接觸居多。
    - 凸輪除了傳送運動外，不適合傳送較大動力。
    - 主要缺點為需藉外力來保持接觸。

## 7.2 凸輪從動件的位移曲線

### 位移圖
- 當凸輪旋轉一圈帶動從動件移動時，由從動件位移相對於凸輪旋轉角度間所繪之圖稱**位移圖**。
- 水平軸表示凸輪旋轉角度，垂直軸表示從動件的位移。

### 速度、加速度與脈衝 (急跳度)
- 由位移對時間的線圖，經過對時間的連續微分，可得速度及加速度對時間的圖形。
- **脈衝 (pulse) 或急跳度 (jerk)**：加速度的斜率改變量。
- **影響**：急跳度代表慣性力對時間變化的度量，也代表負荷衝擊的特性。當凸輪高速運轉時，慣性力會使凸輪產生振動、高應力、噪音及磨損，均會影響凸輪的壽命。

### 7.2.1 等加速度運動

- **位移方程式 (由靜止開始)**：`s = (1/2)At²`
- **凸輪轉角與時間關係**：`t = θ/ω`
- **加速度**：`A = 4hω²/β²`
- **升程期間 (0 ≤ θ ≤ β/2)**：
    - 位移：`s = (1/2)A(θ/ω)² = (2h/β²)θ²`
    - 速度：`V = A(θ/ω) = (4hω/β²)θ`
- **減速期間 (β/2 ≤ θ ≤ β)**：
    - 位移：`s = h - (1/2)A( (β-θ)/ω )² = h - (2h/β²)(β-θ)²`
    - 速度：`V = -A( (β-θ)/ω ) = (4hω/β²)(β-θ)`

### 7.2.2 修正等速度運動

- **等速運動問題**：加速度理論上達到無限大，導致衝擊負荷。
- **修正方法**：在等速運動之前使用一段等加速運動，在等速運動之末尾引用一段等減速運動，以達到防止無限大衝擊發生。
- **特性**：雖然無限大的加速度被消除，但加速度曲線仍不連續，故仍會有衝擊現象。

### 7.2.3 簡諧運動

- **原理**：根據一點 P 沿圓周作等角速運動時，在直徑上的投影。
- **位移方程式**：`s = (h/2)(1 - cos(πθ/β))`
- **速度 V**：`V = (πhω/2β) sin(πθ/β)`
- **加速度 A**：`A = (π²hω²/2β²) cos(πθ/β)`
- **特性**：
    - 速度曲線為正弦曲線，振幅為 `πhω/2β`。
    - 加速度曲線為餘弦曲線，振幅為 `π²hω²/2β²`。
    - 加速度曲線只有當上升和下降階段的凸輪轉角均等於 180° 時，才是連續的。如果轉角不相等或有靜止階段，則加速度曲線就不再連續，亦有衝擊現象。

### 7.2.4 擺線運動

- **原理**：一個圓在直線上滾動，則圓周上一固定點的軌跡為擺線。
- **位移方程式**：`s = h [θ/β - (1/2π) sin(2πθ/β)]`
- **速度 V**：`V = (hω/β) [1 - cos(2πθ/β)]`
- **加速度 A**：`A = (2πhω²/β²) sin(2πθ/β)`
- **特性**：
    - 加速度曲線，連接另一條擺線運動的加速度曲線，在其前後連接靜止階段時都是連續的，故不會產生衝擊現象。
    - 在四種常用運動中，最適合用於高速凸輪。
    - 當給定的時間和對應的升程條件相同時，擺線運動的加速度值，比另外三種常用運動的最大加速度值都大。

### 各運動型式比較

| 運動型式         | 加速度曲線連續性         | 高速凸輪適用性 | 最大加速度值 (相對) |
| :--------------- | :----------------------- | :------------- | :------------------ |
| 等加速等減速運動 | 不連續，有衝擊現象       | 不適用         | 較小                |
| 修正等速度運動   | 不連續，有衝擊現象       | 不適用         | 中等                |
| 簡諧運動         | 條件性連續 (θ=180°時) | 條件性適用     | 中等                |
| 擺線運動         | 連續，無衝擊現象         | 最適用         | 較大                |

## 7.3 凸輪輪廓設計的圖解法

- **設計流程**：根據工作要求，合理選定從動件型式及位移曲線圖後，可用圖解法或解析法繪出凸輪輪廓曲線。
- **圖解法原理**：利用反轉原理，假設凸輪固定，機架及從動件繞凸輪旋轉，在各相位上定出從動件接觸面，切於各相位上接觸點的平滑曲線即為凸輪輪廓。
- **常見從動件類型**：
    - 往復式刃口從動件凸輪
    - 往復式滾子從動件凸輪
    - 往復式平板從動件凸輪
    - 往復式偏置滾子從動件凸輪
    - 擺動式滾子從動件凸輪

## 7.4 壓力角

- **定義**：凸輪輪廓上某一點的壓力角 (φ)，是指該點和從動件接觸時，凸輪輪廓上該點的法線與從動件端點的速度方向線之間所夾的銳角。
- **作用力分解**：凸輪對從動件的作用力 F 可分解為法線分力 F_n 和切線分力 F_t。
    - `F_n = F cos φ`
    - `F_t = F sin φ`
- **設計考量**：通常為使凸輪機構運動良好，推程壓力角不超過 30°。
- **減小壓力角的方法**：
    1. 增大基圓直徑。
    2. 減小從動件的總升程。
    3. 對於定值從動件位移量，用較大的凸輪旋轉角來完成。
    4. 改變從動件的運動型式 (如等速度、等加速、簡諧運動等)。

## 7.5 確動凸輪

- **定義**：凸輪與從動件的接觸，在回程時常須依靠重力或彈簧力，但亦可使用某種確動方式來完成。
- **偏心凸輪 (eccentric cam)**：板形凸輪為圓形，且凸輪的轉軸中心 O 不在圓心上，此種凸輪使從動件產生簡諧運動。

## 7.7 圓柱凸輪

- **應用場景**：從動件的運動方向平行於凸輪轉軸之機構，若用板形凸輪須有較複雜的齒輪系統時，可使用圓柱凸輪。
- **構造**：經由圓柱上之導槽傳遞運動到從動件。
- **從動件運動類型**：可為往復式運動或擺動。
- **應用實例**：工具機、釣繩捲輪之捲繩機構。

## 7.8 反置凸輪 (inverse cam)

- **定義**：機構中各元件的功能剛好相反。
- **特性**：具有凹槽的物體為從動件，而滾子是主動件。

## 7.10 本章重點整理

1.  **從動件運動方式**：
    -   等加速度運動
    -   修正等速度運動
    -   簡諧運動
    -   擺線運動
    -   務必瞭解每種運動方式的位移、速度及加速度公式。

2.  **凸輪輪廓設計**：
    -   從動件的位移運動圖完成後，依從動件的型式與凸輪運動旋轉軸心作基圓，再繪出凸輪輪廓。
    -   注意繪圖時應以何者為圓心，以何為半徑所畫的弧。
