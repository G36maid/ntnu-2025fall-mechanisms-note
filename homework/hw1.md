# 機構學 hw01

## 1.1
試解釋下列名詞

- 機械：將一些固定及活動的剛性物體，配置在產生能量的動力源與輸出能量的作功物之間，做為彼此能量轉換的工具，使彼此能相互適應各得其所。一部機械之組成，至少應包括以下三個部分：接受能量的部分、將接受之能量加以轉換或傳遞的部分、產生「功」或預期效果的部分。

- 機構：多個機件聯接，使機件產生固定之運動但不一定可作功。若運動鏈其中的一根連桿固定，而其它任一根連桿移動至新位置時，將導致其餘連桿移動至可預知的位置，則此系統稱之為「拘束運動鏈」，或稱機構。

- 機件：機械或機構均由剛體或抗力體所組成，這類自成個體之剛體或抗力體。機件可分為靜止機件及活動機件。

- 機器：兩個以上機件的組合體，可將能量轉變為有用的功。如腳踏車、縫紉機等都是機器。機器與機構的不同在於機器必須作功，而機構不一定要作功。

- 連桿：在一部機器中，對其它物體有相對運動者稱之。

- 運動鏈：指一組連桿系統，也就是一群連在一起或相互接觸，而可以做相對運動的剛體。

- 結構或架構：三根連桿互相釘在一起，此種裝置不能構成一組運動鏈，因為其元件之間沒有相對運動，所以不是機構。當自由度F≤0時，該運動鏈為呆鏈，也就是架構或結構。

- 機械運動學：探討機械元件之間相對運動的學問（位移、速度及加速度），並不考慮各機件受力之大小，也不管各機件本身質量之多寡。

- 機械動力學：研究作用在機械元件上的力與經由此力所造成的運動（力、質量、物體的尺寸大小與力施於物體上後產生的運動變化），通常在確定運轉中的元件是否達到平衡，或是強度是否安全時，都必須作動力分析。

- 對偶：任兩物體相接觸則構成一對偶。分為低對（面與面接觸）和高對（點或線的接觸）。

- 自由度：相對於機架或固定桿而言，確定每一根連桿位置所需的最少獨立參數之數目。對一不受任何拘束之剛體而言，其具有六個自由度；一個只在平面運動之剛體則具有三個自由度。
## 1.2
一部機械之組成應包含哪些部分？試舉出五種不同機械並分析部分？

一部機械之組成應包括以下三個部分：
1. 接受能量的部分：接收外界能源的部分
2. 將接受之能量加以轉換或傳遞的部分：能量轉換或傳遞機制
3. 產生「功」或預期效果的部分：輸出有用功的部分

五種不同機械的分析：

1. 腳踏車
   - 接受能量的部分：踏板系統（接受人力）
   - 能量轉換傳遞部分：鏈條齒輪系統
   - 產生功的部分：後輪驅動系統（推進功）

2. 縫紉機
   - 接受能量的部分：電動馬達（接受電能）
   - 能量轉換傳遞部分：皮帶輪、齒輪傳動系統
   - 產生功的部分：針桿機構（縫製功）

3. 汽車引擎
   - 接受能量的部分：燃燒室（接受化學能）
   - 能量轉換傳遞部分：活塞連桿曲軸系統
   - 產生功的部分：飛輪輸出軸（機械功）

4. 電風扇
   - 接受能量的部分：電動馬達（接受電能）
   - 能量轉換傳遞部分：馬達轉子定子系統
   - 產生功的部分：風葉系統（送風功）

5. 挖土機
   - 接受能量的部分：柴油引擎（接受化學能）
   - 能量轉換傳遞部分：液壓系統
   - 產生功的部分：挖斗機構（挖掘功）
## 1.3
試述對偶的種類？

對偶(Pairing)的定義：
任兩物體相接觸則構成一對偶。

對偶的種類：

1. 低對 (Lower Pairing)
- 定義：兩物體若是面與面接觸就構成低對
- 特點：接觸面積較大，磨損較小
- 舉例：
  - 軸承（軸與軸承的接觸）
  - 活塞與汽缸壁
  - 旋轉或銷接頭
  - 滑動對
  - 螺旋對

2. 高對 (Higher Pairing)
- 定義：不考慮機件變形，若兩物體係以點或線的接觸為高對
- 特點：接觸面積較小，會造成較大的磨損
- 舉例：
  - 滾動軸承
  - 齒輪嚙合
  - 凸輪機構
  - 滾珠軸承的點接觸
  - 圓柱滾子軸承的線接觸

對偶與自由度的關係：
在古柏方程式 F = 3(L-1) - 2P₁ - P₂ 中：
- P₁：具有一個自由度之對偶數（如旋轉對、滑動對）
- P₂：具有二個自由度之對偶數目（如某些特殊接頭）
## 1.4
試決定下圖 1.15(a)(b)(c)(d)中何者是拘束運動鍊，無拘束運動鍊或是結構

判斷方法：使用古柏方程式 F = 3(L-1) - 2P₁ - P₂

其中：
- F：平面運動鏈的自由度
- L：連桿數總和
- P₁：具有一個自由度之對偶數
- P₂：具有二個自由度之對偶數目

判斷準則：
- F = 1：拘束運動鏈（機構）
- F > 1：無拘束運動鏈
- F ≤ 0：結構

(A) L = 4, P₁ = 7, P₂ = 0
計算：F = 3(4-1) - 2×7 - 0 = 9 - 14 = -5
結果：結構

(B) L = 5, P₁ = 6, P₂ = 0
計算：F = 3(5-1) - 2×6 - 0 = 12 - 12 = 0
結果：結構

(C) L = 6, P₁ = 7, P₂ = 0
計算：F = 3(6-1) - 2×7 - 0 = 15 - 14 = 1
結果：拘束運動鏈（機構）

(D) L = 5, P₁ = 6, P₂ = 0
計算：F = 3(5-1) - 2×6 - 0 = 12 - 12 = 0
結果：結構
