# 機構學課程筆記

## 課程資訊
- **課程名稱**: 機構學 (Mechanisms)
- **學校**: 國立台灣師範大學 (NTNU)
- **系所**: 機電工程學系

## 課程大綱
本課程涵蓋機構學的基本原理與應用，包括：
- 機械、機構與機件的基本概念
- 機械運動的種類與特性
- 運動分析與設計
- 各種機構的運動原理
